## Assessment answers

1.600 canonical payment SERVER observations in60s give **10 requests/s**.18 explicit ERROR gives **18/600=0.03=3%**. Two INTERNAL spans per operation describe processing already represented by the inbound SERVER; including them would inflate the request denominator and lower the apparent error fraction. UNSET only says no explicit span error was recorded, not that the business transaction succeeded.
2.Sum1450ms/10 gives **mean145ms**. Nearest-rank positions are5,10,10, so **p50=50ms,p95=1000ms,p99=1000ms**. The mean hides nine observations at≤90ms and a1000ms tail. Overall hourly p95 requires the combined distribution (or appropriate mergeable representation); averaging bucket p95 values, even with count weights, does not recover it.
3.**gateway → payment → inventory**. Each service has one inbound SERVER (A,C,F). Each edge has one observed CLIENT/SERVER pair (B→C,E→F). INTERNAL D describes payment's own work; it is not a cross-service CLIENT operation and cannot create another edge.
