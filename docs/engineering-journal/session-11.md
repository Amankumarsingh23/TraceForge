## Definitions and supported subset

Official Gauge, monotonic/non-monotonic Sum and explicit Histogram with delta/cumulative temporality are supported. Typed attributes, schema/scope/resource, units, description, exact integers/nanoseconds, flags and optional histogram fields are preserved within the documented subset. Unsupported points/optional metadata are rejected with point-granular partial success. Sensitive identity attributes are rejected, preventing redaction collisions.

Stream identity includes full typed resource/scope/metric/intrinsic properties/dimensions, with a stored full key beside SHA-256 and stable process instance ID. Gauge/cumulative logical point identity uses stream+end; delta uses stream+start+end. Replays count once. Conflicts preserve raw evidence, select earliest-ingestion/full-content canonical content and remain unreliable. Resource identity and scope distinguish independent writers; bad identical writer configuration cannot be universally repaired.

Point windows use `(from,to]`; exact incremental intervals must be fully covered. Cumulative compatible observations are differenced independently per writer. Known zero sequence starts inside the window can contribute first observations; unknown initial history becomes a baseline. Unknown start metadata remains conditional/unreliable. Confirmed new sequence starts reset correctly; unexplained monotonic decreases do not become negative rates. Delta overlap components are excluded, not double-counted. Gauges are observed values, never event totals. No-recorded-value does not become zero or restart a cumulative sequence. Histograms difference compatible buckets/sums before merge; min/max remain raw, and percentiles are bucket ranges.

See the metric contract for exact limits, schema and unsupported fields. Request batches have no inter-request queue/batch wait; this is bounded synchronous request batching, not a new durable queue. Cardinality admission is process-lifetime and resets with the receiver; it is not persistent fleet-wide quota enforcement. Query resolution is native points, without arbitrary pagination/rebinning. Predecessor horizon is1h; crossing/incomplete intervals remain visible. Unknown starts/conflicts/overflow cannot establish trusted full rates. Namespace is not authenticated tenant isolation. Production TLS/IAM/DLP hardening, live-provider/independent semantic review and full traffic coverage remain unverified. No SLO decisions or alerts were implemented.
